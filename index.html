NU Queue-It

Web Programming course project (v2 rebuild). Original Feb–Mar 2025; rebuilt as a documented Laravel MVP.

A university office queue system for students, staff and admins. Students take a service ticket, staff manage their department’s waiting line, and a public display shows who is being served. First pilot target: Admission (AMS).

  • Laravel 13
  • PHP 8.3+
  • Blade
  • MySQL / MariaDB
  • PHPUnit
View source on GitHub

Local MVP. University sign-in adapters and real-time (Reverb) updates are deferred until pilot hosting is known.

  • Rebuilt an earlier course prototype end-to-end: role-based accounts (student, staff, admin), department and service management, and ticket lifecycle with daily-resetting numbers.
  • Staff can call, complete, skip and recall tickets limited to their department; students create and cancel waiting tickets; a public board shows the ticket being served.
  • Added automatic queue refresh every five seconds, a read-only admin activity log, generated temporary passwords with forced change at first sign-in, and responsive UI states (loading, empty, offline, error, validation).
  • Documented architecture, schema, requirements, test plan and deployment; automated tests with PHPUnit (SQLite) plus a MariaDB integration profile.
